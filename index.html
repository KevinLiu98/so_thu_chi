Hướng dẫn bật Đồng bộ đám mây

Để bật tính năng đồng bộ giữa điện thoại và máy tính, anh cần tạo một project Firebase miễn phí:

  1. Truy cập console.firebase.google.com và đăng nhập bằng tài khoản Google
  2. Nhấn "Add project" → đặt tên dự án → nhấn Create
  3. Vào phần "Authentication" → Sign-in method → bật "Email/Password"
  4. Vào phần "Firestore Database" → Create database → chọn "Start in production mode"
  5. Vào trang chủ dự án → nhấn icon "Web" () → đăng ký app → sao chép đoạn mã firebaseConfig
  6. Mở file index.html → tìm dòng "const firebaseConfig" → thay bằng cấu hình của anh
  7. Upload file lên GitHub lại là xong!

💡 Lưu ý: Khi chưa cấu hình Firebase, ứng dụng vẫn hoạt động bình thường ở chế độ ngoại tuyến, dữ liệu lưu trên thiết bị.
